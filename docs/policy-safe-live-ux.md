# Policy-Safe Live UX

The live-match surface is intentionally contextual.

Allowed MVP behavior:

- Resolve Riot ID to active game.
- Show visible public pre-game selections from Spectator-V5.
- Let the user select their champion and an opponent champion.
- Pre-fill aggregate explorer filters.
- Show multiple historical build patterns with games, winrate, and confidence.

Avoid:

- "Buy this now" or single-command language.
- Claiming certainty from low samples.
- Hidden information that a player would not already know in the current game.
- Arena augment or Arena item winrates.

The UI should make sample size visible and keep the user in comparison mode.
