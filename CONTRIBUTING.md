# Contributions Are Not Accepted

WinRift is Adam Wentworth's solo portfolio application and private production system. This repository is public for review only; it is not a community project and does not accept outside issues, pull requests, code, documentation, design work, or other contributions.

Repository access and maintenance are intentionally limited to the owner. The issue and pull-request forms remain available only for owner-operated project tracking and maintenance.

Do not submit, copy, run, reuse, deploy, redistribute, or derive work from this repository. Public visibility does not grant a license. See [LICENSE](LICENSE) for the controlling terms.

Security concerns may be reported privately through [GitHub's private vulnerability reporting form](https://github.com/AdamWentworth/WinRift/security/advisories/new). Do not place credentials, private infrastructure details, player data, or exploit details in a public issue or pull request.
