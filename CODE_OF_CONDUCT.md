# WinRift Community Code of Conduct

WinRift's public repository exists for respectful technical discussion, product feedback, and carefully scoped collaboration.

## Expected Behavior

- Be constructive, specific, and respectful.
- Critique ideas and implementation choices rather than people.
- Respect privacy, Riot API constraints, and the project's source-available license.
- Give maintainers and contributors room to ask questions, revise work, or decline a proposal.

## Unacceptable Behavior

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing private information, credentials, player data, or exploit details.
- Spam, impersonation, deliberate disruption, or repeated bad-faith demands.
- Using repository participation to imply endorsement by WinRift, Riot Games, or another contributor.

## Enforcement

The repository owner may edit or remove comments, close discussions, decline contributions, or restrict participation when behavior conflicts with this policy. Report conduct concerns privately to the repository owner through GitHub. Do not open a public issue containing sensitive details.

This policy applies to issues, pull requests, reviews, discussions, and other spaces managed by the WinRift repository.
